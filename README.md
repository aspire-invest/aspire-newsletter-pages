# מבט אלטרנטיבי — מסמך רקע לפרויקט

24.9.2026 · אלעד שפרנסקי

## מה זה הפרויקט

"מבט אלטרנטיבי" הוא ניוזלטר שבועי-יומי של Aspire Investments בנושא השקעות אלטרנטיביות (Private Equity, Private Credit, Infrastructure, M&A, Fundraising). המערכת אוספת כתבות רלוונטיות מהעולם, מסננת ומתמצתת אותן בעזרת AI, ושולחת גיליון מעוצב ללקוחות ולנמעני הרשימה.

**חשוב להבין:** אין כאן שום קוד רגיל או ריפו — כל המנגנון בנוי כולו בתוך Make.com (פלטפורמת אוטומציה ויזואלית, "תרחישים" שמחוברים אחד לשני). מי שרוצה לגעת בלוגיקה של הפרויקט צריך גישה לחשבון Make, לא ל-GitHub.

## איך זה עובד מאחורי הקלעים

כל הלוגיקה בנויה כ-Scenarios בחשבון Make.com של הפרויקט. אלו העיקריות:

**איסוף ופרסום (Collector, רץ מדי שעה)** — סורק כתבות RSS, מסנן עם AI אם הן רלוונטיות לניוזלטר, ושומר סיכום ב-Data Store כדי למנוע כפילויות.

**שליחה יומית (Publisher, 09:00)** — בוחר את הכתבות הטובות של היום, בונה את הגיליון ושולח דרך Brevo לכל מנוי הרשימה.

**הרשמה/מחיקה/ביטול** — שלושה סצנות נוספות (Signup, Admin Delete, Admin List, Unsubscribe + Unsubscribe Confirmed) שמטפלות בקישורים מה-Webhooks למעלה.

שלושה מערכות חיצוניות, מתעדכנות בכל פעולה (הרשמה/מחיקה/ביטול):

| מערכת | תפקיד |
| --- | --- |
| **Brevo** | מערכת המשלוח בפועל — שולחת את המיילים למנויים |
| **Make Data Store** | בסיס הנתונים הפנימי של מערכת ה-Make (מנויים + כתבות שעובדו) |
| **Google Sheet** | גיבוי נוח וניתן לשיתוף לרשימת המנויים |

כל פעולה של מנוי (הרשמה/מחיקה/ביטול) מעדכנת את שלושת המערכות בבת אחת — אין צורך לעדכן ידנית בשלושת המקומות.
