# מבט אלטרנטיבי — מסמך רקע לפרויקט

24.9.2026 · אלעד שפרנסקי

## מה זה הפרויקט

"מבט אלטרנטיבי" הוא ניוזלטר יומי של Aspire Investments בנושא השקעות אלטרנטיביות — הון פרטי, אשראי פרטי, תשתיות, מיזוגים ורכישות וגיוסי הון. המערכת אוספת כתבות רלוונטיות מהעולם, מסננת ומתמצתת אותן בעזרת בינה מלאכותית, ושולחת גיליון מעוצב ללקוחות ולנמעני הרשימה.

**חשוב להבין:** אין כאן קוד רגיל או ריפוזיטורי קוד — כל המנגנון בנוי בתוך Make (פלטפורמת אוטומציה ויזואלית, שבה "תרחישים" מחוברים זה לזה). מי שרוצה לגעת בלוגיקה של הפרויקט צריך גישה לחשבון Make, לא ל-GitHub.

## האתרים והקישורים החיים

כל הדפים מאוחסנים בריפוזיטורי הציבורי `aspire-invest/aspire-newsletter-pages` ומוגשים באמצעות GitHub Pages.

| קישור | מה זה | איך זה מחובר |
| ---: | ---: | ---: |
| [subscribe.html](https://aspire-invest.github.io/aspire-newsletter-pages/subscribe.html) | דף הרשמה לניוזלטר — ממלאים שם ומייל ונרשמים אוטומטית. מיועד לקישור בחתימת מיילים יוצאים (למשל חתימת מנכ"ל) | שולח ל-Webhook ב-Make שמוסיף את הנרשם ל-Brevo, ל-Data Store ולגיליון Google |
| [admin.html](https://aspire-invest.github.io/aspire-newsletter-pages/admin.html) | דף ניהול מנויים — רשימה חיה של כל המנויים וכפתור "מחק מכל המקומות". **ללא סיסמה או אימות — ההגנה היחידה היא סודיות הכתובת. אסור לשתף עם גורמים לא מורשים** | קורא ל-Webhook מחיקה שמסיר את המנוי מ-Brevo, מ-Data Store ומגיליון Google באותה פעולה |
| דפי הגיליונות (`issues/*.html`) | הגיליון היומי עצמו, מתפרסם אוטומטית לפי תאריך על ידי תרחיש הפרסום | מוצג בקישור "לקריאת הגיליון המלא" בתוך המייל שנשלח |

שימו לב: פתיחת קובץ ב-GitHub עצמו מציגה את הקוד הגולמי, לא את הדף החי. לצפייה בדף האמיתי יש להשתמש בקישור המלא (`aspire-invest.github.io/...`) ולא בעמוד הקובץ (`github.com/...`).

## איך זה עובד מאחורי הקלעים

כל הלוגיקה בנויה כתרחישים בחשבון ה-Make של הפרויקט. אלו העיקריים:

**איסוף (תרחיש שרץ מדי שעה)** — סורק כתבות חדשות, מסנן בעזרת בינה מלאכותית אילו מהן רלוונטיות לניוזלטר, ושומר סיכום ב-Data Store כדי למנוע כפילויות.

**פרסום ושליחה (תרחיש יומי, 09:00)** — בוחר את הכתבות הטובות של היום, בונה את הגיליון ושולח אותו לכל מנוי ברשימה.

**הרשמה, מחיקה וביטול** — ארבעה תרחישים נוספים (הרשמה, מחיקת מנוי על ידי מנהל, הצגת רשימת מנויים, וביטול הרשמה עצמי) שמטפלים בבקשות המגיעות מהקישורים שלמעלה.

שלוש מערכות חיצוניות מתעדכנות בכל פעולה של מנוי (הרשמה, מחיקה או ביטול):

| מערכת | תפקיד |
| ---: | ---: |
| **Brevo** | מערכת המשלוח בפועל — שולחת את המיילים למנויים |
| **Data Store של Make** | בסיס הנתונים הפנימי של המערכת — מנויים וכתבות שכבר עובדו |
| **גיליון Google** | גיבוי נוח וניתן לשיתוף של רשימת המנויים |

כל פעולה של מנוי מעדכנת את שלוש המערכות בבת אחת — אין צורך לעדכן ידנית בכל אחת בנפרד.
